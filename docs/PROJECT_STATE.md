## 当前限制
1. 所有联网 provider 均可能发生字段、限流或可用性变化；失败时保留原活动历史。
2. 乐咕月频估值只支持月末同日端点归因，不能解释月内路径。
3. 官方滚动 PE 的成分处理与利润计算细节未独立审计。
4. 官方日频 PE 与乐咕月频 PE 在频率、缺失结构和最新数值上存在差异，不可混为一条连续序列。
5. 中证1000乐咕历史从 2014-10 开始，虽覆盖完整 10 个日历年，但短于另外三个指数；全部历史百分位的样本长度不相同。
