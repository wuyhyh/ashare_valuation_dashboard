## 当前限制
1. 新浪和腾讯是第三方公开接口；可用性和字段仍可能变化，应用会拒绝空数据或列结构变化。
2. 日频缺口检查会把部分长假标记为明显间隔，数据不会因此被删除。
3. 乐咕乐股估值为月频第三方口径；月频归因只在真实同日上计算，不能解释月内路径。
4. 其他三个指数尚无同口径真实 PE/PB，前端会显示数据不足，不用演示数据补齐。
