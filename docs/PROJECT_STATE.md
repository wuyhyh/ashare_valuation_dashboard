## 解释限制
1. 隐含代理是指数层面的数学余项，不是成分股实际利润、EPS 或净资产。
2. 指数换样、权重、除数与第三方估值口径差异会影响解释。
3. 当前真实估值为月频，归因算法不会把月频伪装为日频；即使未来补齐指数日线，也可能因共同样本密度不足而拒绝计算。
