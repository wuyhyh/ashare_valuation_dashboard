# v0.9 · 沪深主板市场宽度快照数据审计

## 目标与已编码边界
本版首次支持从 `ak.stock_zh_a_spot_em()` 显式抓取沪深京 A 股**行情快照**，用代码前缀初筛沪深主板股票并分类上涨/平盘/下跌，计算上涨家数占有效成交样本比、涨跌幅中位数和成交额加权涨跌幅。当前 v0.9 属于开发分支，**尚未在真实联网环境验证返回全量完整性**，并不代表已经拥有历史可比较的主板股票池。

- 初筛沪主板：`600 / 601 / 603 / 605`；深主板：`000 / 001 / 002 / 003`。当前是规则初筛，不是官方证券全量身份名册。遇到新的合法前缀，应以交易所证券名录升级规则。
- 排除 B 股、ETF、创业板、科创板、北交所与无法识别代码。
- 包括风险警示股票的“主板全部样本”与排除 ST / 退市风险股票的“可交易参考样本”分别统计。
- 返回了有效价格/涨跌幅/成交额但成交额为零者单列，不等同于价格平盘，也不直接推断其属于停牌。
- 上涨比例分母：有真实报价与正成交额的所选样本；不是交易所全部挂牌家数。
- **采集时间不等于交易日期。** `captured_at_utc` 和 `capture_local_date` 仅为本地采集时刻；目前 `trading_date=None`、`trading_date_verified=False`，不能仅凭周末抓取重播旧行情形成周末“市场宽度”。
- 历史时间曲线尚未激活；须建立可信的交易日/收盘时点确认、完整股票池及连续快照记录。

## 数据安全
- 新快照保存在项目根目录 `breadth.sqlite3`，与原 `valuation.sqlite3` 完全独立，两者均由 `.gitignore` 排除。
- 同一天不同采集时间保留独立 `capture_id`，不会偷偷去重成某个臆造的收盘交易日。
- 网页 `/api/breadth` 为只读，启动 `python app.py` 不会自动联网采集。
- 本地 CSV 受控导入、全市场证券身份核验、历史可比快照/移动均线宽度和行业估值分布尚未实现；开发验收应明确标为待办。
