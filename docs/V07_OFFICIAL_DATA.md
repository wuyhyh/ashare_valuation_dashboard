# v0.7 · 中证指数官方数据实测记录

本分支新增中证指数官方历史数据路径，并已在 2026-10-31 的 macOS 联网环境完成沪深300实测。该路径直接调用 AKShare `stock_zh_index_hist_csindex`，但仍作为可选采集器：不会静默覆盖原有乐咕估值序列，也不会拼接口径不同的数据。

## 实际联网结论

- AKShare 版本：`1.20.18`。
- 请求：沪深300 `000300`，`20160101` 至 `20261030`。
- 实际列：`日期`、指数中英文名称、`开盘`、`最高`、`最低`、`收盘`、涨跌、成交量、样本数量、`滚动市盈率`等。
- 修复开始日期边界后，有效记录 `2628` 条，覆盖 `2016-01-04` 至 `2026-10-30`，识别为日频。
- 收盘点位：首值 `3469.07`，末值 `3985.50`。
- 滚动市盈率：首值 `13.32`，末值 `12.61`。
- 22 个长间隔均对应交易所长假；未插值、未删除极端市场值。

上游在请求开始日不是交易日时会返回一条以开始日为日期、但数值复制自下一交易日的伪记录。例如直接请求 `20160101` 会得到日期为元旦的观测。采集器现在向前多请求一个日历日，再严格过滤回用户要求的日期范围，避免该边界行为污染历史。

## 交叉核验与口径决策

- 官方收盘与本地新浪指数收盘有 `2628` 个共同日期，最大绝对差 `0.005` 点；最近五日差异为千分点量级。因此官方指数收盘通过核验。
- 官方日频 PE 与本地乐咕月频 PE 有 `130` 个共同日期，最大绝对相对差约 `25.22%`。最近五个共同月末差异约为 `3.62%` 至 `11.43%`。
- 该差异说明两个接口的计算或样本口径并不相同。此次只激活官方 `index_close`，保留乐咕 PE/PB 为当前活跃估值序列，不做替换或拼接。

## 数据库操作

导入前已备份：

```text
valuation.sqlite3.backup-pre-v07-official-20261031
```

只导入并激活沪深300官方收盘：

```bash
python -m data_sources.csindex diagnose --index 000300 --start 20160101 --end 20261030
python -m data_sources.csindex update --index 000300 --metric index_close --start 20160101 --end 20261030
```

当前本地活跃序列：

- `index_close`：中证指数官方日频，2628 条，`2016-01-04` 至 `2026-10-30`。
- `pe_ttm`：乐咕月频，259 条，`2005-04-29` 至 `2026-10-30`。
- `pb`：乐咕月频，259 条，`2005-04-29` 至 `2026-10-30`。

SQLite 文件与备份不进入 Git。

## v0.6 与 v0.7 归因密度验证

旧 v0.6 归因只匹配同一真实日期并按日频窗口设定最低密度，因此官方日频收盘与乐咕月频估值组合会被正确拒绝：

- 1年：13 个共同样本，最低要求 109。
- 3年：37 个共同样本，最低要求 328。
- 5年：起点附近超过 7 天容差。
- 10年：121 个共同样本，最低要求 1095。

v0.7 现在读取估值活动序列的真实频率。乐咕月频估值与日频收盘仍只使用真实同日端点，但采用月频质量规则后，1/3/5/10 年分别以 13/37/61/121 个期点计算，完整本机序列覆盖率为 100%。同一自然月出现多个匹配点时直接拒绝，覆盖率按不同月份计数。

仅在内存中使用官方同一响应的日频收盘与日频 PE 验证旧日频算法，可分别得到 1/3/5/10 年 `243/728/1212/2429` 个样本，且对数恒等式残差为 `0`。这不能作为绕过口径核验切换官方 PE 的依据。

## 界面与限制

- 分析卡片新增四指数覆盖面板，逐项显示 PE、PB、指数点位的真实记录数、频率、截止日期和缺失原因。
- 覆盖接口不返回演示序列；无真实数据时明确显示“尚未采集真实数据”。
- 当前只完成沪深300官方源实测与收盘导入。上证50、中证500、中证1000仍需逐项联网核验。
- provider 名称 `csindex_official` 只能显式选择，不进入 `auto` 回退；候选历史明显短于当前活动历史时拒绝切换。
- 官方接口属于经 AKShare 封装的上游服务，仍可能发生字段、限流或可用性变化；诊断命令会在写库前检查字段和指数代码。
