# v0.7 · 官方指数数据接入（第一阶段）

本分支新增可选的中证指数历史数据路径，**不覆盖默认采集器**。它直接读取 AKShare 的 `stock_zh_index_hist_csindex`，可提供同一响应中的指数收盘点位与滚动市盈率。官方接口可用性及实际历史覆盖尚待在 macOS 环境联网验证。

## 运行

先激活项目的 Python 虚拟环境并安装 AKShare：

```bash
python -m pip install -U akshare
python -m data_sources.csindex diagnose --index 000300 --start 20160101 --end 20261030
python -m data_sources.csindex update --index 000300 --metric all --start 20160101 --end 20261030
```

一次 `update` 会显式设置对应指标的 `active_series`；因此在你的真实数据库执行前，**先备份 `valuation.sqlite3`**。如果暂时只想补指数点位、不切换原来乐咕PE的活跃来源：

```bash
python -m data_sources.csindex update --index 000300 --metric index_close --start 20160101 --end 20261030
```

这个路径保留原有乐咕数据、来源接口、方法口径与独立序列 ID；不拼接，也不把模拟响应作为真实市场数据。

## 数据约束

- 校验返回字段 `日期`、`指数代码`、`收盘`，并校验指数代码与请求一致。
- 选择导入 PE 时必须存在 `滚动市盈率` 字段；先完成所有所选指标的验证，再开始持久化。
- 不前向填充、不插值、不将ETF价格冒充指数。
- 若源接口不可用、字段变化、日期不合法、数据不足，拒绝入库。
- 更新失败时记录失败状态，保留此前的历史观测。
- 需要在真实环境人工核对指数发布日期、历史起止日、特殊日期与10年覆盖。上游可能有空值和重复日期。

## 局限及后续工作

1. **目前尚未完成 macOS 真实联网验证**，也未证明该端点能稳定提供全部四大指数的10年历史。
2. 旧 v0.6 归因算法要求足够密集的同日估值与点位；原乐咕月频 PE 不符合高密度条件，切换至中证同源日频 PE 后才有机会运行。
3. v0.7 下一阶段应完成数据来源选择与覆盖率UI、四指数真实序列验收；再实现以可核验成分股数据为基础的市场宽度与行业估值分布。
4. 这不是把 `P/PE` 解释为上市公司实际净利润的证据，也不是投资建议。
