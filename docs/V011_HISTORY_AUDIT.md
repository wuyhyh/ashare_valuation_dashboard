# v0.11 · 历史市场宽度来源核验审计

> 核对日期：2026-11-01（星期日，A股休市）。当前结论：**新浪独立逐股日线参考接口真实联网可用；本机尚无同一真实交易日收盘后采集并正式验收的宽度快照，因此历史趋势、均线、指数背离和估值关系仍不可用。**

## 1. 数据边界
- v0.10 宽度快照来自单一实时行情源，并与采集时点的交易所官方名录交叉核验。即时接口没有可独立信任的报价交易日，采集日期不能自动解释为交易日期。
- v0.9 `mainboard_only`、v0.10 `sh_sz_all_a` / `sh_sz_all_a_with_bse` 不混用；当前股票名单不得回填过去市场宽度。
- 自动化测试中的历史日期、日线和核验证据都标注 `TEST FIXTURE ONLY`，只验证程序行为，不是市场事实。
- 北交所本轮没有独立逐股日线证据，`BSE` / `ALL_A` 历史继续禁用。

## 3. 正式收盘核验规则
- 主行情源与独立日线参考源必须不同；仅允许真实工作日北京时间15:30之后、采集本地日与待核验日相同的快照。
- 沪深四板块官方名录覆盖分别不得低于95%；每板块抽取5只有效成交普通A股，共20只。
- 每只股票必须存在唯一目标日未复权收盘及有效前一交易日收盘；快照价格与参考收盘相对差不得超过0.05%。
- 由参考前收盘推导的涨跌幅必须与快照涨跌幅相差不超过0.02个百分点。
- `--dry-run` 永不写库；正式写入前用 SQLite backup API 创建完整备份，再以事务重读并确认记录在联网期间未变化。
- 单独修改 `trading_date_verified` 无法通过只读历史接口的完整证据门禁。

## 4. 历史与联动实现
- `/api/breadth-trend` 只读同 `source_interface`、`coverage_scope`、统计版本的正式核验记录；同日取最新，不填充缺日。
- 上涨比例5日和20日简单均线只在拥有足够正式核验交易日且窗口相邻点自然日间隔都不超过7天时计算。
- `/api/breadth-linkage` 只做严格同日匹配：
  - 沪深300、中证500、中证1000的指数点位必须识别为日频，探索性宽度/指数差异至少要求20个稠密共同交易日；
  - PE TTM / PB 关系至少要求12个严格同日样本，估值频率必须识别为日频或月频；
  - 不前向填充、不插值、不移动日期匹配；样本不足时返回不可用，不产生相关性或信号。
- 当前真实核验历史为0个交易日，所以上述图表和联动均保持空状态；离线正例不改变这一结论。

## 6. 自动化测试与真实联网的区分
