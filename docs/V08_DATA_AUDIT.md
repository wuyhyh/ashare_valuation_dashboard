## 实测命令（在 Mac 本地运行）

```bash
python app.py diagnose --index 000016 --metric all
python app.py diagnose --index 000905 --metric all
python app.py diagnose --index 000852 --metric all

python app.py diagnose-market --index 000016 --provider sina --start 20160101 --end 20261030
python app.py diagnose-market --index 000905 --provider sina --start 20160101 --end 20261030
python app.py diagnose-market --index 000852 --provider sina --start 20160101 --end 20261030
```

需要先核验字段结构、指数身份、日期、样本数和频率，再批准激活三个新增指数的估值数据。记录对应 AKShare 版本、数据截止日和异常。

如批准后执行 `python app.py update --index all --metric all`，逐项核对 `/api/coverage` 和 `/api/comparison?metric=pe_ttm` / `pb`，检查是否存在不同口径、历史截断、共同日期错位或缺失样本。

## 乐咕“指数”字段的身份验证注意事项

乐咕指数 PB 公开接口样例的 `指数` 字段是**数值型指数点位**，并非指数名称或代码。不要据此做字符串身份比较。实际联网时需确认该列类型，并优先与经过核验的指数点位做最近至少5个**相同交易日**交叉校验，报告最大误差与日期。若上游字段或频率变化，先诊断再决定是否激活，不得默认为指数身份正确。离线样例用数值型点位模拟该字段。

## 估值口径边界

- 乐咕 PE 固定取 `stock_index_pe_lg` 的 `滚动市盈率`；PB 固定取 `stock_index_pb_lg` 的 `市净率`。
- 中证官方 `stock_zh_index_hist_csindex` 的 `滚动市盈率` 是**独立系列**；v0.7 实测与乐咕 PE 最大相对差约25.22%，不自动替换或拼接。
- 历史百分位仅指各指数相对其自身历史的排序，不是四个指数之间的绝对价值排名。
- 未验证三指数实时源，暂不宣称四指数比较已经具备真实数据。

## 每个源必须补齐的审计字段

接口名称与版本、指数代码、参数、字段列表、有效样本数、首末日期、频率、每月缺口、最近五值、最后完整交易日、同日交叉核验、备注及失败原因。
