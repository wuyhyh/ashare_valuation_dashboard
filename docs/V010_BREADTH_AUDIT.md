# v0.10 · 沪深全市场与分板块宽度数据审计

## 范围与口径

v0.10 将 v0.9 的沪深主板时点快照扩展为以下稳定范围：

| 范围 | 定义 |
|---|---|
| `SH_MAIN` | 上交所主板 A 股 |
| `SZ_MAIN` | 深交所主板 A 股 |
| `CHINEXT` | 深交所创业板 A 股 |
| `STAR` | 上交所科创板 A 股，不含 CDR |
| `MAIN_ALL` | `SH_MAIN + SZ_MAIN` |
| `SH_SZ_ALL` | 四个沪深板块合计，页面默认范围 |
| `BSE` | 北交所独立范围，不计入 `SH_SZ_ALL` |
| `ALL_A` | `SH_SZ_ALL + BSE`，仅在北交所验证通过后启用 |

市场范围由交易所名录决定，与个人账户权限、自选股和券商交易权限无关。上涨比例的分母仍是所选范围内具有有效报价且成交额大于零的真实样本；零成交、缺失报价和风险警示股票分别显示。

## 数据接口

2026-11-01 使用 AKShare `1.20.18` 真实联网验证：

- 行情：腾讯证券 / `ak.stock_zh_a_spot_tx`，一次请求返回一个同源采集时点的全 A 股快照。
- 上海主板：`ak.stock_info_sh_name_code(symbol="主板A股")`。
- 科创板：`ak.stock_info_sh_name_code(symbol="科创板")`。
- 深圳主板与创业板：`ak.stock_info_sz_name_code(symbol="A股列表")`，读取返回的 `板块` 字段。
- 北交所：`ak.stock_info_bj_name_code()`。

腾讯实际返回 `code, name, zxj, zdf, turnover` 及 `stock_type` 等字段。本模块只把代码、名称、最新价、涨跌幅、成交额和证券类型用于宽度统计；不使用其中的 PE 字段。

## 数据库迁移与兼容

- `breadth_captures` 增加 `coverage_scope`；`breadth_quotes` 增加 `board` 和 `security_type`，迁移可重复执行。
- 迁移前已生成本地备份 `breadth.sqlite3.backup-before-v010`，该文件和数据库均由 `.gitignore` 排除。
- v0.9 旧捕获回填 `mainboard_only`。旧 API 兼容键仍可读取上海、深圳和主板合计，但不会返回不存在的创业板、科创板、北交所或沪深全市场。
- 同源截断保护只与相同 `coverage_scope` 的上一份快照比较，避免把旧主板 `3,194` 与新沪深全市场 `5,222` 错误比较。
- 不使用当前官方名单回填任何旧日期，不把采集日转换为交易日。

## 尚存限制

1. 即时行情源没有给出已独立核验的交易日期或收盘时点；页面明确提示，历史趋势继续禁用。
2. 东方财富接口在 v0.9 实测受限流影响；本次激活源为腾讯，后续接口字段或可用性仍可能变化。
3. 官方名单只能证明股票池身份和本次代码覆盖，不能证明即时源的价格对应哪一个真实交易日。
4. 风险警示识别基于行情名称，零成交不能等同停牌；二者均不做未经证明的语义升级。
5. 北交所已验证并接入独立范围，但默认“沪深 A 股”严格不包含北交所。
