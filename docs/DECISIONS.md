# 设计决策记录

## D001 · Git 与状态文档是协作事实来源
源码、提交历史及 `docs/` 是 ChatGPT 与 Codex 的共享基准。聊天内容不代表代码已经落盘、提交或推送。

## D002 · 归因使用对数恒等式
将指数点位 `P` 除以估值倍数 `M` 定义为隐含代理 `X`，使用对数收益精确拆分。`X` 不得称为上市公司利润、EPS、账面净资产，也不用于预测未来收益。

## D003 · 严格真实同日匹配
归因只读取当前激活的真实 SQLite 序列，要求正数、相同日期、单序列来源一致、足够密度且没有过大共同日期缺口。不插值、不前向填充、不使用演示数据。

## D004 · 保留现有数据架构
v0.6 不增加数据库表，不迁移或覆盖 v3 schema，不更换行情供应商，也不改变 AKShare PE TTM/PB 字段选择和既有估值统计公式。

## D005 · 原始数据库不进入 Git
`valuation.sqlite3` 及全部备份由 `.gitignore` 排除。浏览器自动化使用明确标记的模拟响应，不能作为真实联网采集成功的证据。

## D006 · 行情提供方隔离与有界回退
每个行情提供方使用独立 `series_id`、来源接口和方法说明。`auto` 仅按新浪、腾讯、东方财富 daily、东方财富 legacy 的顺序做单次有界尝试；成功后不混入其他提供方历史。首次启用或来源切换时尽力与独立接口核验至少 5 个共同交易日，失败则记录 `unavailable`，不能伪称通过。

## D007 · 归因频率由估值序列决定
点位为日频不代表估值为日频。归因读取当前估值活动序列的 `frequency`：日频沿用原密度与最大缺口规则；月频要求至少 75% 同日覆盖、起点在目标日后 45 天内、最多连续缺失 2 个自然月。未知、周频或误分类数据拒绝计算。

## D008 · 月频期数包含首尾观察点
`expected_periods` 按起止月份（含首尾）计算，因此完整 1/3/5/10 年窗口分别是 13/37/61/121 个期点。该字段用于透明展示覆盖率，不改变对数恒等式或既有估值统计公式。

## D009 · 中证官方源只能显式选择
中证指数 `stock_zh_index_hist_csindex` 作为 `csindex_official` 独立来源接入 provider 层，但不加入 `auto` 回退。官方收盘可经明确命令选择并使用独立 `series_id`；官方滚动 PE 与乐咕 PE 口径差异已实测，未经进一步审计不得自动激活、拼接或参与同口径排名。

## D010 · 候选行情不得缩短活动历史
已有活动指数历史时，新候选必须保留原序列的大致起止范围、覆盖跨度和记录规模，否则更新失败并保留原 `active_series`。月频归因要求每个自然月至多一个同日匹配观测，覆盖率按不同月份数计算，禁止用月内重复数据填补缺月。

## D011 · v0.8 扩展必须保持估值口径隔离
本版本先对四个宽基指数使用乐咕的 `滚动市盈率` 与 `市净率` 字段，沿用已存在的 `SOURCE_SPECS` 与唯一 `series_id`；真实是否可用须逐指数实际联网验证。中证官方 PE 独立保留，不与乐咕数据拼接。四指数历史百分位只能表示各自历史相对位置，不能直接解释不同风格指数的绝对投资价值。市场宽度与行业估值分布延后到另行验证全市场成分历史的项目阶段。

## D012 · 数值型指数列只作身份辅助核验
乐咕 `指数` 字段实测为指数点位而非代码或名称。采集时保存其类型说明，并在存在独立指数收盘序列时按真实同日核验最近 5 个共同样本；结果进入 `quality_json.source_identity`。四指数严格比较要求所有已记录的身份核验均为 `passed`。这项核验不等价于证明乐咕估值算法与中证官方算法相同，官方日频 PE 继续独立存储且不自动激活。

## D012 · 市场宽度必须是来源可核验的时点快照
v0.9 的沪深主板上涨/下跌家数只来自真实股票快照，现阶段以六位股票代码前缀保守识别沪主板（600/601/603/605）和深主板（000/001/002/003），并保留 ST 过滤与所有主板两个统计视图。上市主板身份仍需核验官方证券名单。交易量无证据或缺失报价不计入有效成交上涨比例分母，不视为平盘。由于 AKShare A 股即时接口不保证提供可核验的交易日期，捕获时间只能记录采集时刻，不能据此构建完整历史市场宽度。所有股票快照独立写入 `breadth.sqlite3`，保留 `valuation.sqlite3` v3 结构不变。

## D013 · 跨资产观察与股票估值分层
科创50（000688.SH）和创业板50（399673.SZ）属于股票指数；在未核实其历史PE/PB来源前仅展示真实指数价格走势。黄金采用华安黄金ETF（518880.SH）场内非复权价格作用户可交易代理，不是Au99.99现货、不等于基金净值，也不能进行股票PE/PB和盈利归因。三项以独立SQLite存储，并通过 `/assets.html` 研究价格区间、涨跌和回撤。禁止把这些不同单位数据放进原四大宽基PE估值排名。
