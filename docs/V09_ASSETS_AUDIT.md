## 口径约束

1. 科创50、创业板50暂仅支持真实指数收盘点位和历史价格回撤。未验证到有可靠连续历史 PE/PB 的接口之前，不直接借用 `stock_index_pe_lg` 的其他指数名称，也不填充演示 PE。
2. 黄金ETF没有上市公司盈利/净资产，**PE TTM、PB、盈利归因均不适用**，并不会加入已有四指数的估值横向排序。
3. 非复权ETF价格的历史涨跌幅不等于含分红再投资的总回报。未来需要进行ETF份额拆分、基金合同变化与分红审计时，应增加复权独立系列，不得改写已有原始价格。
4. 每条行情写入单独 `asset_prices.sqlite3`，记录证券代码、数据类型、单位、来源接口、采集时间、历史覆盖与日期；该库已在 `.gitignore` 中，不随 GitHub 传播。
5. 严格拒绝空值、未来日期、日期重复、非正/非有限价格、过期超过45天的来源、短历史覆盖已有长历史；更新写入为SQLite事务，不跨提供方拼接。
6. 在价格窗口小于10年时，计算1/3/5/8/10年区间涨跌/回撤时必须有真实接近窗口起点的观测值，否则显示不可用，不能把短窗口伪装成长窗口。本次科创50实测仅约6.8年，10年窗口正确显示历史不足。

## 2026-11-01 真实联网结果

- AKShare 版本 `1.20.18`，三条主序列均为日频、使用原始真实日期，未插值、未前向填充；最新日均为 `2026-10-30`。
- 科创50中证官方交叉源返回 `1,654` 条，包含 `2019-12-31` 基日 `1000`点；主序列共同交易日 `1,653` 条，身份字段为 `000688 / 科创50`。最近30个共同日最大相对收盘差约 `0.000372%`。
- 创业板50与腾讯交叉源有 `3,007` 个共同交易日，最近30日最大相对差约 `0.000187%`。
- 华安黄金ETF与腾讯交叉源有 `3,222` 个共同交易日，最近30日收盘完全一致。东方财富 `fund_etf_hist_em` 在单次诊断中曾返回同样 `3,222` 条，但随后因 `Push2RateLimitError` 不能稳定重现，因此不作默认源。
- 三序列最大自然日间隔均为 `11`天，各有 `4` 个间隔超过10天，均无相邻样本绝对涨跌超过30%。间隔作为质量提示保留，不会自动删除真实行情。
- 10年窗口：创业板50和518880各 `2,430` 个样本；科创50历史不足，不伪装10年。
- 三项交叉核验结果和行情质量结果写入 `asset_prices.sqlite3`；不更改 `valuation.sqlite3` 或已有四指数 PE/PB 口径。

## 价格质量提醒与浏览器自动化
- `asset_watch.py` 报告 `quality.age_days`、`max_gap_days` 和单次相邻样本30%以上跳变的日期。过期超过10天、相邻数据缺口超过20日和极端跳变会在 `/assets.html` 显示警告。
- 警告只表示**可能存在数据缺失或ETF份额调整等问题**，并不自动识别拆分、分红或停牌；对于未复权ETF价格，历史收益仍不是可实现的总回报。
- GitHub Actions 新增 `browser-smoke`，自动在 Chromium 中验收原估值、市场宽度、跨资产三页；全部使用离线模拟 API。新加入的页面和数据质量测试不构成真实 AKShare 验证。真实本机截图为 `artifacts/v09-real-assets-desktop.png` 和 `artifacts/v09-real-assets-mobile.png`。
